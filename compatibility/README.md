# Tessera Clock preview integration

The current Tessera editor deliberately shows a third-party clock face as an icon and example text. Its screensaver manifest has no field for a live preview. A firmware plugin update cannot change that Vue component.

`tessera-saver-preview.patch` is a prepared source patch against Tessera's dev branch, revision `b18ee2f`. It has not been installed into your Home Assistant add-on or submitted upstream.

The patch lets any plugin provide `previews/<saver-id>.png`. Watch Clock includes `previews/watch.png`, generated by the actual firmware bench. Tessera serves the file from the plugin's pinned revision through its existing same-origin image route, and displays it in the Clock drawer. Missing, invalid or undeclared images retain the existing placeholder. The plugin listing continues to use its separate `store.png`.

This is a **static example screenshot**. It does not simulate the selected options or the current time. It requires an updated Tessera editor and backend; updating only the screen firmware cannot enable it. The PNG itself is safe to ship with the plugin before Tessera supports the convention.

## Validation

- 26 related editor tests passed, including the image URL, missing-image fallback and retry after a new plugin revision.
- Two focused backend tests passed for pinned screenshot fetching, caching, invalid and absent files, and rejection of undeclared saver paths.
- ESLint on the changed files, application and test TypeScript checks, and the production Vite build passed.
- The wider Python catalogue suite includes Linux-only file-permission operations (`os.fchmod`) that cannot run unmodified on Windows. Its Linux CI run remains to be performed before upstream integration.

## Apply to a Tessera source checkout

```sh
git switch dev
git apply --check /path/to/tessera-watch-clock-screensaver/compatibility/tessera-saver-preview.patch
git apply /path/to/tessera-watch-clock-screensaver/compatibility/tessera-saver-preview.patch
cd web
npm ci
npm test
npm run build
```

Build the add-on from that checkout using Tessera's normal development instructions. Do not edit Home Assistant's installed container files directly; those edits disappear on update.
